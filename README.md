### 📊 비교 분석 보고서 작성 

```markdown
# 자동화 도구 비교 보고서: Make vs Zapier

## 구현 워크플로우
Google Form 제출 → 조건 분기 → Sheets 기록 + 이메일 알림

## 비교표

| 항목 | Make | Zapier |
|------|------|--------|
| UI 방식 | 스케치 하듯이 자유롭게 구성 | 차트 플로우 방식 |
| 설정 난이도 | 중간 (학습 필요) | 쉬움 (직관적) |
| 무료 플랜 | 1,000 Ops/월 | 100 Tasks/월 |
| 연동 서비스 | 1,500개+ | 6,000개+ |
| 실행 로그 | 단계별 상세 확인 | Task History |
| 조건 분기 | Router (다중 경로) | Filter (통과/차단) |

## 장단점 요약
### Make
- 장점: 복잡한 분기 설계 가능, 무료 Ops 넉넉
- 단점: 초보자 진입장벽 있음

### Zapier
- 장점: 직관적 UI, 연동 앱 많음
- 단점: 무료 플랜 제한 적음

## 도구 선택 가이드
- 복잡한 워크플로우 → Make 추천
- 빠른 간단 자동화 → Zapier 추천
```
