## 장단점 요약
### Make
- 장점: 복잡한 분기 설계 가능, 무료 Ops 넉넉
- 단점: 초보자 진입장벽 있음

### Zapier
- 장점: 직관적 UI, 연동 앱 많음
- 단점: 무료 플랜 제한 적음

## 도구 선택  : 직관적으로 작업하기 쉽고, 무료로 사용가능 빈도가 더 제공되어 MAKE 를 사용

### 🔧 워크플로우 설계

```
[현장 작업자가 Google Form으로 불량 정보 입력]
  - 불량 사진 첨부
  - 불량 유형 선택 (균열/변색/파손 등)
  - 발생 위치 입력
  - 심각도 선택 (상/중/하)
        ↓ Trigger (Form 제출)
        
[조건 분기: 심각도 기준]
    ↓               ↓
[심각도 "상"]    [심각도 "중/하"]
    ↓               ↓
[긴급 이메일     [일반 Sheets
 알림 발송]       기록만]
    ↓
[Google Sheets 불량 대장 자동 기록]
  - 날짜/시간 자동 입력
  - 사진 링크 자동 연결
  - 불량 유형/심각도 기록
```
